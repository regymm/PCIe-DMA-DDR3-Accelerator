# N4L for Documentation

## Introduction
This project introduces a new methodology for documenting projects using the N4L technology for building knowledge graphs. The present articles are to discuss **How to write project Documentation in N4L**, which contributes to explaining how to use the N4L for documenting either Hardware or Software projects along with dealing with the knowledge browser in the **SSTorytime project**, and the second article is **How to convert Documentation in N4L to markdown**, which discusses how to convert the N4L documentation written using the methodology proposed in the first article back to a human-readable documentation. The two methodologies and the used technologies are all open-source available for everyone who wants to use without costly licenses

## Outcomes
The aim is to introduce a new methodology for documenting projects that is:
- conservatory for knowledge instead of being vulnerable of being lost such as the case with traditional papers
- saving more time eliminating the need to write thousands of words for documenting a single project
- portable through making knowledge more accessible instead of having bare words hardly to be understood
- sustainable through making knowledge safe from being either lost or forgotten
- reasonable and easier to interpret
- And further more...

## Target Audience
This project is targetting both Hardware and Software engineers introducing to them a novel methodology for documenting their projects using the N4L technology. It is also very useful for students to document their prototypes and their projects to have that as a proof of their capabilities and to save their work in a sustainable form.
